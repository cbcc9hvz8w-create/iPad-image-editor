# SnapCanvas

iPadで保存済み画像をすばやく整え、Goodnotesなどへ渡すための画像編集PWAです。画像処理はブラウザ内で完結し、サーバーへ画像を送信しません。

## 主な機能

- JPEG / PNG / WebP画像の読み込み
- 切り抜き、リサイズ、回転、反転、傾き補正
- 明るさ、コントラスト、彩度、シャープ、モノクロなどの調整
- PNG / JPEG書き出し、JPEG品質・目標容量の指定
- JPEGのEXIF情報を保持または削除
- 変更履歴、編集前後の比較、設定プリセット
- 複数画像への一括処理
- インストール後のオフライン利用

## ローカル起動

Node.js 22.13以降とpnpm 11以降を使用します。

```bash
corepack enable
pnpm install
pnpm dev
```

表示されたローカルURLをブラウザで開いてください。

## 確認とビルド

```bash
pnpm typecheck
pnpm test
pnpm build
```

## GitHubへのアップロード

1. このZIPを解凍します。
2. GitHubで新しい空のリポジトリを作成します。
3. リポジトリ画面の **Add file → Upload files** を選びます。
4. 解凍したフォルダの中身をすべてアップロードしてコミットします。

ZIP自体を1ファイルとして置くのではなく、解凍した中身をアップロードしてください。`node_modules`やビルド生成物は含めていません。

## PWAについて

Service Workerは本番環境ではHTTPSが必要です。一度オンラインでインストールしてキャッシュが作成されると、主要画面と画像編集機能をオフラインで利用できます。iPadでは共有シートから「画像を保存」またはGoodnotesを選ぶ使い方を想定しています。

## プライバシー

読み込んだ画像と編集処理は端末内で完結します。プリセット以外の画像データをアプリが永続保存することはありません。
